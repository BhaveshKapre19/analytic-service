# Coding Rules

- **Code Style**: Follow PEP8 formatting.
- **Views**: Use Class-Based Views (CBVs) or DRF ViewSets / APIViews.
- **Environment Variables**: Use `.env` file for all secrets and configurations.
- **Validation**: All incoming data must be validated through DRF Serializers.
- **Docstrings**: Include basic docstrings for important classes and functions.
