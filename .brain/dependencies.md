# Dependencies

- `Django`: Web framework.
- `djangorestframework`: API framework for Django.
- `django-cors-headers`: Allows Cross-Origin Resource Sharing (CORS) for the API.
- `django-filter`: For API endpoint filtering (e.g. by website, date).
- `python-dotenv` & `django-environ`: For managing environment variables (.env).
- `user-agents`: For parsing the raw `navigator.userAgent` string into browser/device info.
